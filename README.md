# N-RICH Digisation Capabilities

## About N-RICH

The National Research Infrastructure for Cultural Heritage (N-RICH) Prototype is a two-year investment in the UK’s world-renowned cultural heritage collections,
funded through a UK Research and Innovation (UKRI) Infrastructure Fund Preliminary Activity grant awarded to the Arts and Humanities Research Council (AHRC), 
and delivered by the Towards a National Collection (TaNC) programme in collaboration with AHRC. The N-RICH Prototype will deliver targeted early-stage activities 
to reduce future investment risks. It will test the key elements and examine the scope, costs, risks, impacts and benefits of a future digital research 
infrastructure for cultural heritage in the UK. Core activities will include a digitisation capability pilot (DCP), a prototype infrastructure, and three cross-cutting
research frameworks on environmental impact, ethics, and cybersecurity.

## About The Digitisation Capabilty Pilot

This project will design, test, cost and establish the priorities of a scalable methodology for digitisation across diverse cultural heritage collection types. 
This will include data capture and metadata creation and augmentation with a focus on the use of machine learning and Generative AI to accelerate data production.

Specifically, the project does not proscribe particular file or metadata formats, or specific systems. 
However, it will address the following aspects of digitisation work flows:

- The digtisation process itself:
  - Quality standards for digitisation (primarily focussing on imaging)
  - Required metadata that should be collected and made available for digitised materials
    - Authority recommendations to enhance interoperabiltiy and discovery 
- Making digtised materials available as part of N-RICH
  - Standardised API which MUST be used to make digitised materials available
    - File format transformation recommendations to faciltate API implementation 
  - Standardised APIs under which metadata MUST be made available as part of N-RICH
    - Mappings between metadata standards in common use and the DCP required metadata to facilitate API implementation
  - Persistent identifier recommendations to ensure robust reference, citation and attribution mechanisms
